# LEXIA - Project Glossary

| Term | Definition | Example |
|------|-----------|---------|
| EPIC | Major feature set | EPIC 3: AI Role-Play |
| Sprint | 2-week development cycle | Sprint 1: Auth + Core Setup |
| Placement Test | Initial assessment | Determines user's CEFR level (A1-C2) |
| Role-Play | Speaking practice scenario | "Small Talk at Work" |
| Sandbox | Safe practice area | Grammar Sandbox for exercises |
| SRS | Spaced Repetition System | Algorithm for flashcard review |
| CEFR | Language proficiency levels | A1, A2, B1, B2, C1, C2 |
| JWT | JSON Web Token | Auth mechanism |
| JSONB | PostgreSQL JSON type | Stores AI-generated content |
| Streak | Consecutive learning days | User's 5-day streak |

### Abbreviations
- API = Application Programming Interface
- JWT = JSON Web Token
- SRS = Spaced Repetition System
- CEFR = Common European Framework of Reference
- CRUD = Create, Read, Update, Delete
- MVP = Minimum Viable Product
- XP = Experience Points
