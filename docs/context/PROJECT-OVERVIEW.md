# LEXIA - Project Overview

## Business Vision
Create the most practical AI-powered English platform for working 
professionals (25-45 years old) who need daily communication skills 
improvement without overwhelming theory.

## Problem Statement
- Traditional English apps are boring, generic, not practical
- Working professionals need real-world scenarios (emails, meetings, small talk)
- AI can personalize learning but most apps don't leverage it effectively
- Need a platform that actually helps them speak better at work

## Solution
LEXIA: An adaptive platform with:
- AI-generated role-play scenarios for speaking practice
- Context-aware grammar exercises (user's own topics)
- Adaptive learning paths based on placement test
- Gamification to build daily habit
- Multi-platform access (web + mobile)

## Target Users
- **Primary**: Working professionals aged 25-45
- **Secondary**: Business English learners
- **Pain Points**: Limited time, need practical skills, fear of mistakes
- **Motivation**: Career advancement, confidence in meetings/presentations

## Success Metrics (MVP)
- [ ] User can complete placement test → get level assessment
- [ ] User can generate 5+ AI role-play scenarios
- [ ] User can complete grammar sandbox exercises
- [ ] Daily active users maintain 3+ day streak
- [ ] System handles 100 concurrent users
