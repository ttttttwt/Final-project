# LEXIA Content Expansion Plan

## 📋 Tổng Quan

Tài liệu này đề xuất kế hoạch mở rộng nội dung cho nền tảng LEXIA một cách có hệ thống, bao gồm: Courses & Lessons, Role Play Scenarios, Grammar & Vocabulary, Multimedia Content, và Learning Paths.

**Mục tiêu**: Tạo nền tảng học tiếng Anh toàn diện cho người đi làm với nội dung đa dạng, thực tế và hấp dẫn.

## 3. 📝 Grammar Exercises & Vocabulary

### 3.1 Grammar Exercise Structure by Level

#### A1 - Beginner (500+ exercises)

| Category | Topics | Exercise Types |
|----------|--------|---------------|
| **Verbs** | Present simple (be, have), Imperatives | Fill-in-blank, Multiple choice |
| **Nouns** | Singular/plural, Articles | Matching, Error correction |
| **Pronouns** | Subject pronouns, Possessive adjectives | Substitution, Gap-fill |
| **Questions** | Yes/no, Wh- questions | Sentence reordering, Matching |
| **Other** | There is/are, Basic prepositions | Picture description, Fill-in-blank |

#### A2 - Elementary (800+ exercises)

| Category | Topics | Exercise Types |
|----------|--------|---------------|
| **Verbs** | Past simple, Present continuous, Going to | Tense selection, Story completion |
| **Modals** | Can/can't, Have to, Would like | Situation matching, Dialogue completion |
| **Comparatives** | More/less, -er/-est, As...as | Comparison writing, Gap-fill |
| **Connectors** | And, but, because, so | Sentence combining, Error correction |

#### B1 - Intermediate (1000+ exercises)

| Category | Topics | Exercise Types |
|----------|--------|---------------|
| **Verbs** | Present perfect, Past continuous, First conditional | Timeline exercises, Sentence transformation |
| **Modals** | Should, must, might, could | Advice giving, Prediction exercises |
| **Passive** | Present/past simple passive | Active to passive, News headline analysis |
| **Reported Speech** | Statements, Questions | Direct to reported, Dialogue transformation |
| **Relative Clauses** | Who, which, that | Clause combining, Definition writing |

#### B2 - Upper Intermediate (1200+ exercises)

| Category | Topics | Exercise Types |
|----------|--------|---------------|
| **Verbs** | Past perfect, Second conditional, Future perfect | Complex timeline, Hypothesis writing |
| **Advanced Passive** | All tenses, Passive with modals | Academic text analysis, Formal writing |
| **Conditionals** | Third conditional, Mixed conditionals | Regret expressions, Alternative history |
| **Clauses** | Non-defining relative, Participle clauses | Academic writing, News analysis |
| **Other** | Wish/if only, Inversion | Formal register, Emphasis exercises |

#### C1 - Advanced (800+ exercises)

| Category | Topics | Exercise Types |
|----------|--------|---------------|
| **Complex Structures** | Cleft sentences, Fronting | Style analysis, Formal writing |
| **Perfect Modals** | Must have, Should have, Could have | Speculation, Criticism expressions |
| **Discourse** | Advanced linking, Hedging language | Essay writing, Academic argument |
| **Style** | Register shifting, Formal/informal | Editing, Style transformation |
